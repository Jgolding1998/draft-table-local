# Contributing

Run `python -m unittest discover -s tests -v` before proposing a change. Keep the application local-only and free of runtime services, analytics and account requirements.

For interface changes, check a keyboard-only flow and a 390-pixel-wide viewport. For storage or request-handling changes, include a regression test for the failure you fixed.

Use synthetic designs and comments in reports and screenshots. Do not upload client work, private records, credentials or a local database. AI-assisted contributions are welcome when the contributor reviews the change, can explain it, and identifies the assistance used.
