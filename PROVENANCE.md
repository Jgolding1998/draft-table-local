# Source and asset provenance

This is a fresh public edition of a generic design feedback idea. No private repository history, client names, logos, uploaded images, comments, contacts, configuration or saved data are included.

The backend, request guards, raster validation and tests were written for this edition by Codex. An earlier private prototype was inspected only to understand basic upload, comment, reply and delete interactions. No code or assets from that prototype were copied into this edition.

Claude Code owns the HTML, CSS and JavaScript interface work. It was instructed to use its locally installed `unslop` design guidance and to work without external fonts, analytics, CDNs or paid services. These tools are acknowledged as development assistance, not redistributed runtime dependencies. Unslop's author and CC BY 4.0 license are credited in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The files under `examples/` are synthetic raster drawings made from simple shapes and generic text for this edition. They contain no client work or real records. Development-only image generation and browser automation tools are outside the product and are not needed to run it.

The only runtime is Python 3.11+ and its standard library, including SQLite. No third-party source, icon library, font file or application dependency is bundled. The original project code and synthetic example images are provided under the repository's MIT license.

The linked projects in the design notes informed interaction decisions. Their code, logos and assets were not reused; their licenses do not become this project's license.
